# Submission checklist

Deadline: **Nov 12, 2026, 12:00pm PST** (20:00 UTC). Aim to submit by the evening of **Nov 11** to leave a buffer. Devpost saves drafts, so start the form early.

Taken from the hackathon's rules page. Judges start with a pass/fail check that the project really uses PayPal's developer platform, then score five equal criteria: Technological Implementation, Design, Potential Impact, Innovation, Presentation.

## Repository
- [ ] Public repo on GitHub, GitLab or Bitbucket
- [ ] **MIT `LICENSE` file at the root**, and GitHub shows the licence in the repo's **About** section
- [ ] Contains all source code, assets and instructions needed to run it
- [ ] README has complete setup and run steps (see [README.md](../README.md))
- [ ] README lists **sandbox test logins** and any keys judges need (sandbox only, never live secrets)
- [ ] No real secrets committed (see TEST_PLAN F13)
- [ ] Commit history shows the work happened after Oct 1, 2026

## Working demo
- [ ] Hosted URL works from a private browser window
- [ ] Persona switcher means no signup is needed
- [ ] The keep-awake ping is running through the judging window (Dec 1–15)
- [ ] The whole [TEST_PLAN.md](TEST_PLAN.md) passes against the hosted app

## Demo video
- [ ] **Under 3 minutes**. Judges aren't required to watch beyond that.
- [ ] Shows the project working end-to-end on the device it was built for (a browser)
- [ ] Uploaded to **YouTube**, set to **Public**
- [ ] No copyrighted music or third-party trademarks used without permission. Use royalty-free music or none.
- [ ] Clear on: what problem, who it's for, why it matters (the Presentation criterion)
- [ ] Script: [DEMO_SCRIPT.md](DEMO_SCRIPT.md) *(to write once the build exists)*

## Devpost form
- [ ] Project name, tagline: *"Piko makes PayPal the default way AI agents pay, and get paid."*
- [ ] Text description: features and functionality (adapt README sections)
- [ ] **Tools section**: every AI model and service used and *how* it's used (Gemini, PayPal Agent Toolkit, Claude Code)
- [ ] PayPal products used: Orders v2, JS SDK, Payouts, Invoicing, Webhooks, Agent Toolkit
- [ ] Sponsor tools used: Channel3, AG Grid, APIMatic, Postman, Render
- [ ] Links: repo, hosted demo, YouTube video
- [ ] Screenshots: playground, org console, seller console
- [ ] All teammates added to the Devpost project
- [ ] Everything in English

## Final checks
- [ ] Every link works from a logged-out browser
- [ ] Submitted (not just saved as a draft) before the deadline
