# 0010. The product is named Piko

**Status:** Accepted · 2026-11-04

## Context
Earlier candidates clashed with existing companies: Meter (meter.com), Paywire (an existing payments company with a registered trademark), AgentTab (the "Tab" agent-payments project), Drip, Tickpay, Fluxpay, Dime, Paylo, Tikk and others.

## Decision
Name: Piko (chosen 2026-11-04).

## Consequences
Known risks: a pending US trademark "PIKO" (serial 99117355, Piko Labs AI, Inc.) covers classes 36 (financial services) and 42 (software), and the npm name `piko` and GitHub user `piko` are taken. Acceptable for a hackathon; decide again before taking Piko further as a product. Use a scoped npm name (e.g. `@<org>/piko-sdk`) and a GitHub org other than `piko`.
